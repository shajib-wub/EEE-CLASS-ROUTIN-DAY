🔧 GitHub Setup Required for Cross-Device Sync

To make all users see the same data, please configure GitHub:

  1. Go to https://github.com/settings/tokens
  2. Click "Generate new token (classic)"
  3. Select "repo" scope
  4. Copy the generated token
  5. Open browser console (F12) and run: configureGitHub("your_username", "repo_name", "token")

After setup, all changes will sync to ALL devices automatically!
